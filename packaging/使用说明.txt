iPhone-PC 便携版（Windows x64）
================================

使用方法
--------
1. 将整个压缩包解压到一个固定位置；不要在压缩包内直接运行。
2. 双击“启动 iPhone 投屏.cmd”。
3. 第一次启动时，如 Windows 请求安装 Bonjour 服务或请求防火墙访问，请允许。Bonjour 的安装需要管理员确认；防火墙请选择专用网络。
4. 在 iPhone 打开控制中心 → 屏幕镜像，选择电脑上显示的接收名称。

默认接收名称：iPhone-PC
默认连接密码：6817

名称、密码、分辨率和帧率可在工作台右侧修改。修改后点击保存或应用，iPhone 需要重新连接。

“画面缩放”提供 50%、75%、100% 三档，选择后立即生效。缩放只改变居中画面的大小，窗口大小不变，不需要重新连接。支持工作台内显示、普通窗口、最大化和全屏，所选比例会保存。

独立窗口的顶部栏浮在画面上方；鼠标静止约 2 秒或移出窗口后隐藏，窗口内移动鼠标时显示。顶部栏显示或隐藏时画面大小固定。普通窗口可拖动四周边缘或角落调整大小，顶部可拖动窗口，并提供最小化、最大化、返回工作台及全屏按钮。

运行要求
--------
- Windows 10 或 Windows 11，x64（Intel / AMD）
- iPhone 与电脑处在同一局域网
- 支持 Direct3D 11 的显卡
- 系统自带的 .NET Framework 4.x（通常已随 Windows 10/11 提供）

首次运行提示
------------
压缩包内已包含投屏接收核心、运行库和 Bonjour 组件，不需要另行安装投屏软件。首次运行仍可能出现 Windows 的管理员确认和防火墙确认；如果拒绝，iPhone 可能找不到本机。

请在首次成功启动后保留该解压文件夹的位置。接收组件会把 Bonjour 服务关联到该文件夹；若之后移动了整个文件夹而投屏不可用，请重新从“启动 iPhone 投屏.cmd”启动并按提示允许修复。

数据与兼容性
------------
本包不含这台电脑的设置、密码、日志或源码。首次启动会在本文件夹创建 data 目录保存你的设置；接收核心还会使用当前 Windows 用户的 AppData 配置与日志目录。

分辨率和帧率是向 iPhone 提出的请求，实际视频规格仍由手机、网络和视频片源决定。受 DRM 保护的视频服务可能只显示黑屏或没有画面。
